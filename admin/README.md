# اتاق فرمان

صفحهٔ `admin/index.html` از لینک موجود در هدر سایت (`admin/`) باز می‌شود و از `store.js` مشترک استفاده می‌کند. تمام مسیرها نسبی‌اند تا روی GitHub Pages و زیرمسیر ریپوزیتوری نیز کار کنند.

## ورود و محدودیت امنیتی

- مشخصات اولیه همان مشخصات از قبل تنظیم‌شده در `store.js` است؛ این تغییر رمز اولیه را عوض نمی‌کند.
- امکان تغییر نام کاربری و رمز در پنل وجود دارد. رمز به صورت متن ساده ذخیره یا صادر نمی‌شود؛ فقط هش سازگار با ذخیره‌ساز قبلی نگهداری می‌شود.
- نشست محلی بعد از ۸ ساعت منقضی می‌شود و پس از ۵ ورود ناموفق، وقفهٔ ۵ دقیقه‌ای اعمال می‌شود.
- **این سایت استاتیک است. ورود، نشست و محدودیت تلاش‌ها فقط در مرورگر اجرا می‌شوند و قابل دور زدن‌اند. این پنل مرز امنیتی، احراز هویت سمت سرور یا محل نگهداری اطلاعات محرمانه نیست.** برای مدیریت امن و انتشار مستقیم باید بک‌اند و احراز هویت واقعی اضافه شود.

## ذخیره و انتشار

1. مشخصات نمونه‌کارها، لینک سایت و اطلاعات تماس را ویرایش کنید.
2. «ذخیره در این مرورگر» پیش‌نمایش محلی را به‌روزرسانی می‌کند؛ تب‌های باز همان مبدأ از طریق `BroadcastChannel` مطلع می‌شوند.
3. «دریافت فایل انتشار» نسخهٔ کامل `data.json` را می‌دهد. سایر قسمت‌های سایت مثل هویت، خدمات، فرم تماس و مهارت‌ها حفظ می‌شوند.
4. فایل خروجی را جایگزین `data.json` در ریشهٔ ریپوزیتوری و از مسیر معمول GitHub منتشر کنید. این پنل خودش به GitHub چیزی ارسال نمی‌کند.
5. بعد از تغییر رمز، دریافت و انتشار خروجی باعث انتقال هش جدید به مرورگرهای دیگر می‌شود. تنظیم رمز محلی در هر مرورگر اولویت دارد؛ برای برگشت به تنظیم منتشرشده باید کلید `pf:cred` همان مرورگر پاک شود.

ویرایش تصاویر، افزودن و حذف پروژه‌ها و ویرایش سایر بخش‌ها فعلاً در این رابط پیاده‌سازی نشده‌اند.

## تست

تست‌های بدون وابستگی:

```sh
node --test tests/*.test.cjs
```

تست مرورگر اختیاری با Playwright و Chromium نصب‌شده (وابستگی‌ها را بیرون از ریپوزیتوری نصب کنید):

```sh
python3 -m http.server 8000 --bind 0.0.0.0
# در ترمینال دیگر، بعد از نصب Playwright و Chromium:
NODE_PATH=/path/to/dependencies/node_modules node tests/admin.browser.cjs
```

متغیر `TEST_BASE_URL` برای آدرس سرور دلخواه پشتیبانی می‌شود. تست مرورگر از مشخصات آزمایشی در یک نشست جدا استفاده می‌کند و فایل دادهٔ ریپوزیتوری را تغییر نمی‌دهد.
